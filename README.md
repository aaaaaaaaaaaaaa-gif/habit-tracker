# Habit Tracker

선택한 시간표형 디자인을 구현한 React/Vite 웹앱. 완료/미완료, 시작일, 목표, 기록은 브라우저 localStorage에 저장된다. 서버 데이터베이스와 외부 API는 사용하지 않는다.

진행률 = 현재 마일스톤 내 완료 목표 / 해당 마일스톤 전체 목표 수. 종료일 없는 챌린지는 7·30·90일 마일스톤을 반복한다. 새 브라우저와 기기는 각자 별도 기록을 갖는다.

`npm ci`, `npm run dev`, `npm run build`로 실행·빌드한다. `qa/mobile.html`은 개발 중 모바일 비교에만 쓰며 배포 빌드에는 포함되지 않는다.

이번 버전은 일일 목표·기록·진행률·달력 기록을 우선 구현한다. 통계는 완료 횟수와 날짜별 기록을 제공하고, 주간 계획은 기존 목표의 예정 시간을 날짜별로 저장한다. 고급 프로젝트 관리, 운동 수치·사진 아카이빙은 이번 핵심 MVP 범위 밖이다.
